# Self-host Server Port — Implementation Plan (sub-project A)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the canvas API from Cloudflare Worker to a standalone Bun + Hono + Drizzle + SQLite server in a new `server/` directory, with 1:1 endpoint compatibility against the current CF Worker.

**Architecture:** New `server/` Bun project parallel to `worker/`. Hono mounts one sub-app per route concern. Drizzle ORM owns the SQLite schema and migrations. Typed storage modules expose named CRUD functions (no generic key-value abstraction). Pino for structured logging; Zod for env + request validation; typed error classes mapped by one error-handler middleware. Production hosted canvas keeps using the CF Worker for the duration of this plan.

**Tech Stack:** Bun (runtime + test runner + sqlite + env loader), Hono (HTTP framework), Drizzle ORM + Drizzle Kit (DB + migrations), `bun:sqlite` (built-in), Pino (`pino-pretty` in dev), Zod (`@hono/zod-validator` for request bodies).

## Global Constraints

- **1:1 API compatibility** with the current CF Worker — same URL paths, same request/response shapes. Frontend flips `VITE_CANVAS_API` to use either backend.
- **No CF-specific abstractions** in the new code. Drizzle typed CRUD per table; no `KVStore` interface, no `expirationTtl`, no `env.KV` passing.
- **Tests co-located** as `*.test.ts` next to source files; run under `bun test` against in-memory SQLite.
- **Production canvas-8j0.pages.dev unaffected** — hosted canvas keeps using the CF Worker.
- **Frontend changes are limited to env vars** — `VITE_CANVAS_API` is the only client-side dial.
- **Migrations idempotent on every boot** — `bun start` against an existing DB is a no-op; against a fresh DB it creates schema.
- **Typed `PlexHttpError`** replaces the deferred `msg.includes(' 404 ')` cascade in `sources/plex.ts`. Music-section error context is wrapped properly. Both deferred code-review items fixed in this port.
- **Error JSON shape**: `{ error: { code: string, message: string } }` for every error response.
- **One reaper interval** (5 min) sweeps all storage modules.
- **No build step** — `bun src/index.ts` runs TypeScript directly; no `dist/`.

import { z } from 'zod';

const ConfigSchema = z.object({
  PORT: z.coerce.number().int().min(1).max(65535).default(8787),
  HOST: z.string().default('0.0.0.0'),
  LOG_LEVEL: z.enum(['trace', 'debug', 'info', 'warn', 'error']).default('info'),
  NODE_ENV: z.enum(['development', 'production', 'test']).default('production'),
  CANVAS_DB_PATH: z.string().default('./data/canvas.db'),
  CANVAS_ALLOWED_ORIGINS: z.string()
    .default('http://localhost:5173')
    .transform((s) => s.split(',').map((t) => t.trim()).filter(Boolean)),
});

export type Config = z.infer<typeof ConfigSchema> & { version: string };

export function parseConfig(env: Record<string, string | undefined>): Config {
  const parsed = ConfigSchema.parse(env);
  return { ...parsed, version: env.npm_package_version ?? 'dev' };
}

function load(): Config {
  try {
    return parseConfig(process.env as Record<string, string | undefined>);
  } catch (err) {
    console.error('Invalid configuration:');
    if (err instanceof z.ZodError) {
      for (const issue of err.issues) {
        console.error(`  ${issue.path.join('.')}: ${issue.message}`);
      }
    } else {
      console.error(err);
    }
    process.exit(1);
  }
}

export const config: Config = load();
```

export class HttpError extends Error {
  constructor(public readonly status: number, message: string, public readonly code: string) {
    super(message);
    this.name = 'HttpError';
  }
}

export class PairNotFoundError extends HttpError {
  constructor(code: string) {
    super(404, `Pair session "${code}" not found`, 'PAIR_NOT_FOUND');
  }
}

export class PairExpiredError extends HttpError {
  constructor(code: string) {
    super(410, `Pair session "${code}" expired`, 'PAIR_EXPIRED');
  }
}

export class SourceNotFoundError extends HttpError {
  constructor(key: string) {
    super(404, `Source "${key}" not found`, 'SOURCE_NOT_FOUND');
  }
}

export class BadRequestError extends HttpError {
  constructor(message: string) {
    super(400, message, 'BAD_REQUEST');
  }
}

export class UpstreamError extends HttpError {
  constructor(
    public readonly upstreamStatus: number,
    public readonly upstreamUrl: string,
    message: string,
  ) {
    super(502, message, 'UPSTREAM_ERROR');
  }
}

export class PlexHttpError extends UpstreamError {
  constructor(status: number, path: string, body: string) {
    super(status, path, `Plex ${status} ${path}: ${body.slice(0, 200)}`);
    this.name = 'PlexHttpError';
  }
}

import type { ErrorHandler } from 'hono';
import { HttpError } from '../errors';
import { logger } from '../log';

export const errorHandler: ErrorHandler = (err, c) => {
  if (err instanceof HttpError) {
    logger.warn({ url: c.req.url, code: err.code, status: err.status }, err.message);
    return c.json({ error: { code: err.code, message: err.message } }, err.status as 400 | 404 | 410 | 500 | 502);
  }
  logger.error({ url: c.req.url, err: err.stack ?? err.message }, 'unhandled error');
  return c.json({ error: { code: 'INTERNAL', message: 'Internal server error' } }, 500);
};
```

import type { MiddlewareHandler } from 'hono';
import { logger } from '../log';

export function requestLog(): MiddlewareHandler {
  return async (c, next) => {
    const start = performance.now();
    await next();
    const ms = Math.round(performance.now() - start);
    logger.info(
      { method: c.req.method, path: new URL(c.req.url).pathname, status: c.res.status, ms },
      'request',
    );
  };
}

- [ ] **Step 1: Write the schema**

`server/src/db/schema.ts`:
```ts
import { sqliteTable, text, integer, index } from 'drizzle-orm/sqlite-core';

// Payload shapes — typed JSON columns. Schema is per-table; route handlers
// cast at the boundary.
export interface PairPayload {
  // For type='plex': may carry baseUrl/token after approval
  // For type='flixify': carries pin/pinUrl/mirror during pending, source after approval
  [k: string]: unknown;
}

export interface SourceStatusPayload {
  // Snapshot of the source-status response (publiclyReachable, lastSeenAt, …)
  [k: string]: unknown;
}

export const pairSessions = sqliteTable(
  'pair_sessions',
  {
    code: text('code').primaryKey(),
    type: text('type', { enum: ['plex', 'flixify'] }).notNull(),
    status: text('status', { enum: ['pending', 'approved', 'expired'] }).notNull(),
    payload: text('payload', { mode: 'json' }).$type<PairPayload>().notNull(),
    createdAt: integer('created_at').notNull(),
    expiresAt: integer('expires_at').notNull(),
  },
  (t) => ({
    expiresIdx: index('pair_sessions_expires').on(t.expiresAt),
  }),
);

export const sourceStatusCache = sqliteTable(
  'source_status_cache',
  {
    sourceKey: text('source_key').primaryKey(),
    status: text('status').notNull(),
    lastSeenAt: integer('last_seen_at'),
    expiresAt: integer('expires_at').notNull(),
    payload: text('payload', { mode: 'json' }).$type<SourceStatusPayload>().notNull(),
  },
  (t) => ({
    expiresIdx: index('source_status_cache_expires').on(t.expiresAt),
  }),
);

export type PairSession = typeof pairSessions.$inferSelect;
export type NewPairSession = typeof pairSessions.$inferInsert;
export type SourceStatusCacheRow = typeof sourceStatusCache.$inferSelect;

import type { Db } from '../db';
import { pairSessions, type NewPairSession, type PairSession, type PairPayload } from '../db/schema';
import { nowSec } from '../lib/time';

export function getPairSession(db: Db, code: string): PairSession | null {
  const row = db.select().from(pairSessions).where(eq(pairSessions.code, code)).get();
  return row ?? null;
}

export function createPairSession(db: Db, input: NewPairSession): PairSession {
  db.insert(pairSessions).values(input).run();
  const row = getPairSession(db, input.code);
  if (!row) throw new Error(`createPairSession: row not found after insert (code=${input.code})`);
  return row;
}

  db.update(pairSessions).set({ payload }).where(eq(pairSessions.code, code)).run();
}

export function setPairSessionStatus(
  db: Db,
  code: string,
  status: PairSession['status'],
): void {
  db.update(pairSessions).set({ status }).where(eq(pairSessions.code, code)).run();
}

export function deletePairSession(db: Db, code: string): void {
  db.delete(pairSessions).where(eq(pairSessions.code, code)).run();
}

export function reapPairSessions(db: Db, now: number = nowSec()): number {
  const result = db.delete(pairSessions).where(lt(pairSessions.expiresAt, now)).run();
  return result.changes ?? 0;

import type { Db } from '../db';
import { logger } from '../log';
import { reapPairSessions } from './pair-sessions';
import { reapSourceStatus } from './source-status';
import { nowSec } from '../lib/time';

const REAP_INTERVAL_MS = 5 * 60_000;

export function startReaper(db: Db): () => void {
  const tick = () => {
    const now = nowSec();
    const pair = reapPairSessions(db, now);
    const status = reapSourceStatus(db, now);
    if (pair + status > 0) {
      logger.debug({ pair, status }, 'reaped expired rows');
    }
  };
  tick(); // sweep immediately on startup
  const handle = setInterval(tick, REAP_INTERVAL_MS);
  return () => clearInterval(handle);
}

import { zValidator } from '@hono/zod-validator';
import { z } from 'zod';
import type { Db } from '../db';
import {
  createPairSession, getPairSession, setPairSessionStatus,
  updatePairSessionPayload, deletePairSession,
} from '../storage/pair-sessions';
import { BadRequestError, PairExpiredError, PairNotFoundError } from '../errors';
import { nowSec } from '../lib/time';
import { startFlixifyPair, pollFlixifyPair } from '../sources/flixify';
import { resolvePlexServers } from '../sources/plex';

const PAIR_TTL_SEC = 10 * 60;

function newCode(): string {
  // 6-char A-Z 0-9, formatted XXX-XXX (matches worker behavior)
  const chars = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';
  let out = '';
  for (let i = 0; i < 6; i++) out += chars[Math.floor(Math.random() * chars.length)];
  return `${out.slice(0, 3)}-${out.slice(3)}`;
}

interface DbBinding { db: Db }

export function makePairRoutes(getDb: () => Db) {
  const r = new Hono();

  // ---- Plex pair ----

  r.post('/start', async (c) => {
    const code = newCode();
    const now = nowSec();
    createPairSession(getDb(), {
      code,
      type: 'plex',
      status: 'pending',
      payload: {},
      createdAt: now,
      expiresAt: now + PAIR_TTL_SEC,
    });
    return c.json({ code, expiresAt: (now + PAIR_TTL_SEC) * 1000 });
  });

  r.post('/poll',
    zValidator('json', z.object({ code: z.string() })),
    async (c) => {
      const { code } = c.req.valid('json');
      const session = getPairSession(getDb(), code);
      if (!session) throw new PairNotFoundError(code);
      if (session.expiresAt < nowSec()) {
        setPairSessionStatus(getDb(), code, 'expired');
        throw new PairExpiredError(code);
      }
      const payload = session.payload as { source?: unknown };
      return c.json({
        status: session.status,
        sourceType: session.type,
        source: session.status === 'approved' ? payload.source : undefined,
      });
    },
  );

  r.post('/approve',
    zValidator('json', z.object({
      code: z.string(),
      type: z.enum(['plex', 'flixify']),
      baseUrl: z.string().url(),
      token: z.string(),
      label: z.string(),
    })),
    async (c) => {
      const body = c.req.valid('json');
      const session = getPairSession(getDb(), body.code);
      if (!session) throw new PairNotFoundError(body.code);
      if (session.expiresAt < nowSec()) throw new PairExpiredError(body.code);
      updatePairSessionPayload(getDb(), body.code, {
        source: {
          type: body.type,
          baseUrl: body.baseUrl,
          token: body.token,
          label: body.label,
        },
      });
      setPairSessionStatus(getDb(), body.code, 'approved');
      return c.json({ ok: true });
    },
  );

  r.post('/plex-servers',
    zValidator('json', z.object({ token: z.string(), clientId: z.string() })),
    async (c) => {
      const { token, clientId } = c.req.valid('json');
      const servers = await resolvePlexServers(token, clientId);
      return c.json({ servers });
    },
  );

  // ---- Flixify pair ----

  r.post('/flixify-start',
    zValidator('json', z.object({ code: z.string() }).optional()),
    async (c) => {
      const body = (await c.req.json().catch(() => ({}))) as { code?: string };
      const code = body.code ?? newCode();
      const now = nowSec();
      const flixify = await startFlixifyPair(); // returns { pin, pinUrl, mirror }
      createPairSession(getDb(), {
        code,
        type: 'flixify',
        status: 'pending',
        payload: { pin: flixify.pin, pinUrl: flixify.pinUrl, mirror: flixify.mirror },
        createdAt: now,
        expiresAt: now + PAIR_TTL_SEC,
      });
      return c.json({ code, ...flixify });
    },
  );

  r.post('/flixify-poll',
    zValidator('json', z.object({ code: z.string() })),
    async (c) => {
      const { code } = c.req.valid('json');
      const session = getPairSession(getDb(), code);
      if (!session) throw new PairNotFoundError(code);
      if (session.type !== 'flixify') throw new BadRequestError(`code ${code} is not a flixify pair`);
      if (session.expiresAt < nowSec()) throw new PairExpiredError(code);
      const payload = session.payload as { pin?: string; source?: unknown };
      // If already approved, return cached source.
      if (session.status === 'approved') {
        return c.json({ status: 'approved', source: payload.source });
      }
      // Poll upstream; on success, persist source + mark approved.
      const result = await pollFlixifyPair(payload.pin ?? '');
      if (result.status === 'approved' && result.source) {
        updatePairSessionPayload(getDb(), code, { ...payload, source: result.source });
        setPairSessionStatus(getDb(), code, 'approved');
        return c.json({ status: 'approved', source: result.source });
      }
      return c.json({ status: 'pending' });
    },
  );

  // ---- Delete ----

  r.delete('/:code', async (c) => {
    const code = c.req.param('code');
    deletePairSession(getDb(), code);
    return c.json({ ok: true });
  });

  return r;
}
```

Note the `makePairRoutes(getDb)` factory pattern — the route file doesn't reach into a module-level `db` singleton, which keeps tests trivial.

import { Hono } from 'hono';
import { zValidator } from '@hono/zod-validator';
import { z } from 'zod';
import { BadRequestError } from '../errors';
import { getAdapter } from '../sources/registry';
import type { Item, HomeRow } from '../sources/types';
import { mergeHomeRows } from '../lib/x-sources';

const SourceInput = z.object({
  key: z.string(),
  type: z.enum(['plex', 'jellyfin', 'flixify', 'generic']),
  baseUrl: z.string().url(),
  token: z.string(),
  label: z.string(),
});

export const homeRoutes = new Hono();

homeRoutes.get('/',
  zValidator('query', z.object({ sources: z.string() })),
  async (c) => {
    const sourcesParam = c.req.valid('query').sources;
    let sources: z.infer<typeof SourceInput>[];
    try {
      sources = z.array(SourceInput).parse(JSON.parse(sourcesParam));
    } catch {
      throw new BadRequestError('Invalid sources query param (must be JSON array)');
    }
    const perSource: { source: string; rows: HomeRow[] }[] = [];
    const errors: { source: string; status: number; message: string }[] = [];
    const libraryCounts: Record<string, number> = {};
    await Promise.all(sources.map(async (s) => {
      try {
        const adapter = getAdapter(s.type);
        const ctx = { baseUrl: s.baseUrl, token: s.token };
        const rows = await adapter.home(ctx);
        perSource.push({ source: s.key, rows });
        // libraryCounts come from the source's library list (cheap fetch)
        const lib = await adapter.library(ctx);
        libraryCounts[s.key] = lib.items.length;
      } catch (e) {
        errors.push({
          source: s.key,
          status: 502,
          message: e instanceof Error ? e.message : String(e),
        });
      }
    }));
    return c.json({
      rows: mergeHomeRows(perSource),
      errors,
      libraryCounts,
    });
  },

import { Hono } from 'hono';
import { zValidator } from '@hono/zod-validator';
import { z } from 'zod';
import type { Db } from '../db';
import { BadRequestError } from '../errors';
import { getAdapter } from '../sources/registry';
import { getSourceStatus, putSourceStatus } from '../storage/source-status';
import { nowSec } from '../lib/time';

const SourceInput = z.object({
  type: z.enum(['plex', 'jellyfin', 'flixify', 'generic']),
  baseUrl: z.string().url(),
  token: z.string(),
});

const CACHE_TTL_SEC = 5 * 60;

export function makeSourceStatusRoutes(getDb: () => Db) {
  const r = new Hono();

  r.get('/',
    zValidator('query', z.object({ key: z.string(), source: z.string() })),
    async (c) => {
      const { key, source } = c.req.valid('query');
      let s: z.infer<typeof SourceInput>;
      try { s = SourceInput.parse(JSON.parse(source)); }
      catch { throw new BadRequestError('Invalid source query param'); }

      // Cache hit
      const cached = getSourceStatus(getDb(), key);
      if (cached && cached.expiresAt > nowSec()) {
        return c.json(cached.payload);
      }
      // Miss — fetch from adapter, store, return
      const adapter = getAdapter(s.type);
      const status = await adapter.status({ baseUrl: s.baseUrl, token: s.token });
      putSourceStatus(getDb(), {
        sourceKey: key,
        status: status.status ?? 'unknown',
        lastSeenAt: status.lastSeenAt ?? null,
        expiresAt: nowSec() + CACHE_TTL_SEC,
        payload: status as unknown as Record<string, unknown>,
      });
      return c.json(status);
    },
  );

  return r;
}

export const subtitlesRoutes = new Hono();

subtitlesRoutes.get('/',
  zValidator('query', z.object({ url: z.string().url() })),
  async (c) => {
    const { url } = c.req.valid('query');
    const upstream = await fetch(url);
    if (!upstream.ok) {
      throw new UpstreamError(upstream.status, url, `subtitles fetch failed: ${upstream.status}`);
    }
    const text = await upstream.text();
    return new Response(text, {
      headers: { 'content-type': 'text/vtt; charset=utf-8' },
    });
  },

# canvas-server

Self-hosted backend for canvas. Bun + Hono + Drizzle + SQLite. Ports the

Sub-project A of the self-host roadmap. See

## Requirements

- Bun 1.1+
- A modern Linux/macOS/Windows shell
- Optional: `docker` for the eventual container build (not in scope here)

## Local dev

```bash
cd server
bun install
cp .env.example .env       # customise PORT, DB path, allowed origins
bun dev                     # hot-reload server on :8787
```

## Commands

| Command | Purpose |
|---|---|
| `bun dev`           | Hot-reload server |
| `bun start`         | Production start (no hot-reload) |
| `bun test`          | Run all `*.test.ts` |
| `bun test --watch`  | Watch mode |
| `bun run typecheck` | `tsc --noEmit` |
| `bun run db:generate` | Diff `schema.ts` → emit new SQL migration |
| `bun run db:migrate`  | Apply pending migrations against `CANVAS_DB_PATH` |
| `bun run db:studio`   | Drizzle's web UI on the local DB |

## Environment

Documented in `.env.example`. All have sensible defaults except
`CANVAS_ALLOWED_ORIGINS`, which you usually want to set to the canvas
frontend URL (`http://localhost:5173` in dev).

## Storage

SQLite at `CANVAS_DB_PATH` (default `./data/canvas.db`, WAL mode). Mount
this directory as a Docker volume for persistence. Schema lives in
`src/db/schema.ts`; migrations in `drizzle/`. Sub-project B will add
user accounts + source-sync tables alongside the existing two.

## Tests

Co-located `*.test.ts`. Each test file gets its own in-memory DB. Run
`bun test` to execute all of them; integration tests use `app.fetch()`
directly so no port is bound.

## Production deploy

Out of scope for this sub-project (sub-project D handles Docker + TLS).
Today this server is intended for local development against the
existing hosted canvas frontend.
