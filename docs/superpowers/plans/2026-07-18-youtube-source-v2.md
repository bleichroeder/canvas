# YouTube Source v2 — dedicated destination + followed feed

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Turn the YouTube source from a (broken) Home contributor into its own
destination — a source card that opens a YouTube-specific page of search + a
self-curated feed of **followed channels/playlists**. No sign-in. Fix the
extraction-reliability gaps found in local testing.

**Builds on:** the shipped v1 (adapter, signed stream route, add-source, Docker
with yt-dlp+ffmpeg). See design: `docs/superpowers/specs/2026-07-18-youtube-source-addendum.md`.

## Global constraints

- Still additive to Plex/Flixify. `youtube.home()` returning `[]` is the only
  change to shared-Home behavior.
- Server: `bun test` + `bun run typecheck`. Web: `npm run build`. No web test fw.
- Commits: NO `Co-Authored-By` / Claude footer. Migrations via `bun run db:generate`.
